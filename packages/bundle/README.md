# @danielng23/dsh-edex-novafleet-ui

**DeepSeek Harness eDEX-UI shell plugin — NovaFleet Mission Control theme.**
Dark navy mission-control skin (background `#0f1726`, card surface `#1e2938`,
accent `#3b82f6`, 1px `#334155` rounded card borders, flat dashboard).

![dsh-edex-ui-novafleet screenshot](screenshot.png)

## Widgets

- Left: MISSION DASHBOARD (countdown + stat tiles) · MISSION METRICS · ANNOUNCEMENTS
- Right: NETWORK STATUS · FLEET CALENDAR (featured, replaces WORLD VIEW globe) · MISSION RESOURCES
- Bottom: DIR · PREVIEW · TERMINAL
- Center: the original DSH UI framed by a `NOVAFLEET WORKSPACE` title bar card

See the root `analysis.json` / `analysis.md` for the full reference breakdown.
